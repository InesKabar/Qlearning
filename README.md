# Qlearning
QLearning Algorithm 

A Python project that demonstrates the Q-Learning reinforcement learning algorithm by training an agent to find an efficient path through a graph toward a defined goal.

## Project Overview

The project represents a set of connected states as a graph. A reward matrix is used to define possible movements and reward reaching the goal state.

The Q-Learning algorithm is then trained through multiple iterations to learn the best actions for navigating the graph.

## Technologies

- Python
- NumPy
- NetworkX
- Matplotlib

## How It Works

1. Create a graph representing connected states.
2. Define a reward matrix for possible movements.
3. Initialize a Q-matrix.
4. Train the Q-Learning algorithm over multiple iterations.
5. Test the trained model by starting from a given state.
6. Display the most efficient path to the goal.
7. Visualize the training scores.
